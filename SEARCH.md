# Search names

The official project name is **Sloppy Context Actions** (`Sloppy-Context-Actions`). It is a Unity Editor extension that adds context actions to the Project window.

If you landed here by searching for **Slopy Context Actions**, **SlopyContextActions**, or **SloppyContextActions**, this is the same project. “Slopy” (one `p`) is a common misspelling of “Sloppy.”

- Repository: https://github.com/zORg-alex/Sloppy-Context-Actions
- Unity Editor context menu actions
